## 1. 模块范围

本模块为 Aurora Music 引入**来源无关的音乐获取能力**：

- 统一的来源适配器契约（搜索、播放解析、认证、播放权限）
- 来源注册表与生命周期管理
- 跨来源搜索的聚合与失败隔离
- 播放能力与元数据的**类型级分离**

首批设计两个适配器：

| 适配器 | 目标 | 当前状态 |
|---|---|---|
| `NavidromeMusicSource` | 用户自建的 Navidrome 服务器，经 Subsonic 兼容 API | 设计完成，**未实现、未连接** |
| `GdStudioMusicSource` | GD Studio API | **占位设计**，API 文档未核实，**不得启用** |

## 3. 与现有架构的关系

### 3.1 ⚠️ 必须先记录的冲突

本模块的设计稿要求产出 TypeScript 接口 `MusicSource` 与 `MusicSourceRegistry`。
**这与现有架构存在直接冲突，此处记录而不擅自解决：**

| 冲突点 | 现有约束 | 出处 | 本模块的处置 |
|---|---|---|---|
| C-1 | 前端**不得**直接发起任意网络请求 | `requirements.md` NFR-4.2 | TS 侧**不实现**适配器；`MusicSource` 接口在 TS 中只作为契约声明与投影类型，真实实现在 Rust |
| C-2 | 未验证 URL 不得进入音频引擎 | `architecture.md` P4 | 用 `ResolvedPlayback` 的 `unique symbol` 品牌在 TS 侧复现同一约束，与 Rust 侧 `ResolvedStream` 私有字段同构 |
| C-3 | `AudioSource` / `QueueEntry` 的路径字段是 `PathBuf`，**只能表达本地文件** | `domain/ports.rs:22`、`domain/queue.rs:21` | 远程播放需要扩展这两个类型 —— **属现有文件修改，本阶段不做**。扩展方案见 `interface-design.md` §7 |
| C-4 | `src/ipc/client.ts` 是全项目唯一出现 `invoke()` 的位置 | `src/ipc/client.ts:2` | 已核实边界完好。来源相关 IPC 必须继续走该文件，不得新开通道 |

**结论：** 本模块的运行时实现必须落在 Rust 侧（`infra/sources/`），
TS 侧的 `types.ts` 是契约与投影，不是实现。
详细论证见 [`interface-design.md`](interface-design.md) §1。

### 3.2 现有可复用的基础设施

| 能力 | 现有位置 | 复用方式 |
|---|---|---|
| 错误信封 | `domain/error.rs` 的 `AppError` + `ErrorPayload` | 来源错误映射为现有 code 体系，**不新增并行通道** |
| 数据库 | `infra/db/`（rusqlite + 迁移） | 来源配置存 `source_configs` 表（schema 中已预留） |
| 测试框架 | Rust 侧 105 个测试 | 来源契约测试沿用同一套 |
| 时间源 | `domain/ports.rs` 的 `Clock` trait | 过期判定用注入时钟，保证测试确定性 |

### 3.3 当前缺失、实施前需补齐

| 缺失项 | 影响 | 处置 |
|---|---|---|
| **无任何 HTTP 客户端依赖** | Rust 侧无法发起请求 | 实施阶段需引入（`Cargo.toml` 目前无 reqwest/hyper 等） |
| **无前端测试框架** | TS 侧无法跑单测 | 本阶段只做类型检查；测试计划见 `testing-plan.md` |
| **无密钥环集成** | 凭据无处安全存放 | 见 `security-and-errors.md` §2 |
| **`source_configs` 表未创建** | 来源配置无处持久化 | schema v1 未含该表，需新增迁移 |

## 4. 架构

```
┌─────────────────────────────────────────────────────────────┐
│ 前端 (React/TS)                                             │
│  · 来源列表、启用开关、认证状态显示                          │
│  · 搜索结果（含"不可播放"置灰态）                            │
│  ⛔ 不发起网络请求（NFR-4.2）                                │
│  ⛔ 不构造 ResolvedPlayback                                  │
└──────────────────────────┬──────────────────────────────────┘
                           │ IPC（唯一通道 src/ipc/client.ts）
┌──────────────────────────▼──────────────────────────────────┐
│ commands/sources.rs（薄适配器，本阶段不创建）                │
└──────────────────────────┬──────────────────────────────────┘
┌──────────────────────────▼──────────────────────────────────┐
│ app/ · SourceRegistry（编排、跨来源聚合、失败隔离）           │
└──────────────────────────┬──────────────────────────────────┘
┌──────────────────────────▼──────────────────────────────────┐
│ domain/ · MusicSource trait + ResolvedStream（私有字段）      │
└──────────────────────────┬──────────────────────────────────┘
┌──────────────────────────▼──────────────────────────────────┐
│ infra/sources/                                              │
│   ├── local.rs        （本地来源，包一层现有资料库）          │
│   ├── navidrome.rs    （Subsonic 兼容）                      │
│   └── gdstudio.rs     （占位，不启用）                        │
└─────────────────────────────────────────────────────────────┘
```

**关键不变式：** 来源适配器**只能**产出 `ResolvedStream`
（Rust）/ `ResolvedPlayback`（TS 投影）。播放引擎的签名只接受该类型，
因此"忘记校验就播放"在编译期即不可能。

## 5. 实施顺序

```
S0 文档与契约（本阶段）──► S1 Rust 侧接口与本地来源 ──► S2 注册表与持久化
                                                          │
                                                          ▼
                                          S3 Navidrome 适配器（首个真实来源）
                                                          │
                                                          ▼
                                          S4 队列/播放器跨来源扩展
                                                          │
                                                          ▼
                                          S5 GD Studio（**阻塞于文档核实**）
```

**S5 有硬前置条件：** GD Studio 的 API 文档、许可条款与播放授权未获可靠证据前，
该适配器**不得启用**、**不得返回伪造的可播放结果**。
它将以 `placeholder: true` 注册并在 UI 中显示为"暂不可用"。
